# Controller Studio

Bem-vindo ao Controller Studio! Este é o projeto final desenvolvido para a disciplina de Computação Gráfica. Aqui, você encontra um simulador de controles de videogame que une uma interface de loja virtual com um motor gráfico 3D funcional.

## O que é este projeto?
O Controller Studio é um estúdio virtual onde você pode visualizar e interagir com modelos 3D de controles. O grande diferencial é que o motor gráfico foi construído do zero, permitindo que as peças do controle respondam em tempo real aos comandos, além de simular processos de manutenção e personalização estética.

## Como mexer no simulador
Para interagir com o controle na tela, utilize os comandos abaixo:

* **Girar o controle:** Clique e arraste com o botão esquerdo do mouse para visualizar o controle de todos os ângulos.
* **Zoom:** Utilize a rodinha do mouse (scroll) para aproximar ou afastar a visualização.
* **Controle Remoto:** Se você tiver um controle de videogame conectado ao seu computador, o simulador irá detectar automaticamente o input. Você verá os analógicos, botões e gatilhos se movimentarem na tela conforme você pressiona os comandos físicos.
* **Customização:** Na interface da loja, você pode alterar as cores da carcaça do controle para ver como ele ficaria com diferentes designs.

## Tecnologias utilizadas
* **p5.js & WebGL:** A base para renderizar os gráficos 3D no navegador.
* **Algoritmo Catmull-Clark:** Utilizado para transformar formas geométricas simples em superfícies curvas e suaves, garantindo que o controle tenha uma aparência realista e polida.
* **Matemática Vetorial:** O "cérebro" do projeto, responsável por calcular como a luz reflete no controle e como ele se movimenta no espaço 3D.
